# Documentação da API B2B da ClubTrack

Fonte do site de documentação para parceiros que integram pela API B2B da ClubTrack, publicado em
[docs.clubtrack.com.br](https://docs.clubtrack.com.br).

A API está em **BETA**. Para dúvidas, bugs ou ajuda na integração, fale com a ClubTrack pelos canais que você já conhece.

## O que há aqui

| Caminho | O que é |
|---|---|
| `docs.json` | Tema, navegação e configuração do site ([Mintlify](https://mintlify.com)) |
| `index.mdx`, `primeira-chamada.mdx`, `guias/` | Guias de conceito e de integração |
| `referencia/` | Uma página por operação da API, com parâmetros, respostas, erros e exemplos |
| `historico-de-mudancas.mdx` | O que mudou na API |
| `images/`, `logo/`, `favicon.png`, `style.css` | Identidade visual |

## Ver o site no seu computador

```bash
npm i -g mint
mint dev   # abre em http://localhost:3000
```

## Dúvidas ou erros na documentação

Se uma página não bater com o que a API faz, avise a ClubTrack pelos canais que você já conhece. Informe a página, a chamada que fez e o
`message` que recebeu, sem enviar a sua chave de API.
